# UML 类图编辑器

单文件、离线可用的 UML 类图编辑器（纯 HTML + 原生 SVG，零依赖）。

在线使用：<https://slatinwine.github.io/uml-editor/>

## 功能

- 类 / 接口 / 抽象类 / 枚举 / 注释节点，属性方法分区，`+ - # ~` 可见性着色
- 关联、泛化、实现、组合、聚合、依赖六种关系，支持标签与多重性
- 拖拽 / 平移 / 缩放，撤销重做，自动保存（localStorage）
- 导入导出：`.uml`（JSON）、PlantUML `.puml`、SVG、PNG（2×）

## 使用

直接打开 `index.html` 即可，无需服务器。
